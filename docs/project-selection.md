# 求职项目选题与范围

目标岗位：机器视觉 / YOLO 应用工程师。目标用户：应聘者用于演示，面试官用于审阅；业务模拟用户为 PCB 质检人员。

| 候选 | 可展示能力 | 主要限制 | 本次取舍 |
|---|---|---|---|
| 车辆检测与过线计数 | YOLO、ByteTrack、事件规则、轨迹和统计 | 使用现成模型时自有训练与数据工程内容偏少 | 可做第二项目 |
| PPE 安全装备检测 | 自定义数据训练、类别不平衡、人员装备关联 | 现场遮挡与装备归属复杂，需要额外验证 | 可选 |
| PCB 缺陷检测与复核 | 自定义训练、小目标、模板配准与差分、评估协议、错误分析 | 公开数据与现场差异大，需清晰注明 | 选用 |

以上是按求职作品可展示能力作出的工程判断，不是招聘数量统计。

依据：[Ultralytics 目标计数](https://docs.ultralytics.com/guides/object-counting/)、[Construction-PPE 数据说明](https://docs.ultralytics.com/datasets/detect/construction-ppe/)、[DeepPCB 原始数据](https://github.com/tangsanli5201/DeepPCB)。

## 产品简报

- **问题与价值**：单张画框演示不能证明完整工程能力；本作品提供从公开标注到训练、独立评估、实际推理和人工复核的可追溯链路。未进行企业用户访谈，不声称已验证商业需求。
- **核心场景**：载入测试或自有图像，选择算法和阈值，查看缺陷位置与类别，记录人工判断，导出结果；另有模型评估与批量推理场景。
- **MVP**：六类 YOLO11n 检测、模板差分、切片推理、数据审计、真实评估、单用户中文界面、复核 SQLite、简历与讲解材料。
- **不包含**：机械臂、尺寸计量、PLC、实时相机标定、云端多租户、生产合格判定、收费、未经实测的模型优化提升。
- **产品形态与规模**：Windows 本地 Streamlit 应用，单用户；上传单张不超过 15 MB / 1600 万像素；离线批量推理由 CLI 提供。
- **商业模式与成本**：个人作品，不收费；免费公开数据与开源依赖，本机 CPU，不购买云 GPU 或服务。
- **安全与权限**：仅监听 127.0.0.1，无账号、无需密钥；公开样例与自选图片本地处理；仅加载项目指定模型，不开放上传可执行模型文件。
- **技术方向**：Python 3.12、Ultralytics YOLO11n、OpenCV、PyTorch、Streamlit、SQLite；保留 model hash、数据 hash、运行参数。
- **里程碑**：数据审计→训练与验证→独立测试与误检分析→界面验证与文档。CPU 训练耗时实测后记录，不预先承诺精度。
- **团队与维护**：AI 辅助个人开发；应聘者需根据讲解文档掌握设计与限制。重训练、数据更新与依赖维护由项目持有人负责。
- **验收**：启动可用、真实权重能推理、独立测试产生指标、复核可保存、导出能打开、核心测试通过、没有虚构数字。
- **风险**：CPU 算力限制、公开数据含人工补充缺陷、来源 group 重叠、误检漏检、现场域差异；限制写入 README 与模型卡。
