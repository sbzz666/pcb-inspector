# 面试讲解与动手练习

## 90 秒项目介绍

我做了一个基于 YOLO11n 和 OpenCV 的 PCB 缺陷检测与复核系统。它识别断路、短路、缺口、毛刺、余铜和针孔六类缺陷。我从 DeepPCB 原始标注开始，完成 YOLO 格式转换、图像去重审计和训练验证测试隔离；用验证集选择置信度，再在独立测试图片上评估。

为比较传统视觉和深度学习，我实现了模板差分基线，并把位置检测和类别判断分开统计。应用层支持测试样例、图片上传、切片检测、人工确认误检、SQLite 复核留痕和结果导出。性能数字来自本机评估文件。这是公开数据上的个人作品，还没有接入真实产线。

## 面试官会继续问什么

**1. 为什么用 YOLO，而不是只做模板差分？**

差分在模板已配准、成像稳定时具有速度和定位优势，但需要无缺陷模板，本实现不能直接识别六类缺陷。YOLO 不需要模板、可输出类别，但需要标注和训练，存在漏检与域偏移。比较时要说明输入条件不同，不能预设 YOLO 在所有场景更好。

**2. 原始标注怎么转换？**

DeepPCB 是 `x1 y1 x2 y2 class`，类别编号 1—6。YOLO 是 `class xc yc w h`，类别减 1，坐标按图像宽高归一化。代码先检查类别范围、正面积和边界，避免把无效标注静默写入训练集。

**3. 怎么避免数据泄漏？**

保持原作者 test 列表归属；只从 trainval 内划验证集；检查 ID 和解码像素 SHA256 重复；不把模板放入待测训练图像；置信度在验证集选择。当前仍允许不同集合共享 PCB group，所以不能声称跨版型泛化。更严格的下一步是按板型、原始大图、拍摄批次分组隔离。

**4. 为什么小缺陷难检测？**

原图缩小到 320 时，小缺陷可只剩几个像素。提高输入尺寸和切片可能保留细节，但会增加计算量，并导致边界截断与重复框。切片先保持原图坐标映射，再按类别做全局 NMS；效果仍需独立实验，不能只凭视觉演示宣称提升。

**5. IoU、置信度和 NMS 有什么不同？**

IoU 衡量两个框的重叠；部署置信度过滤低分预测；NMS 用框间 IoU 删除同类重复预测；评估中的 IoU 阈值决定预测框与真值是否匹配。它们作用不同，不应混用。本项目 NMS=0.45，固定阈值评估 IoU=0.5。

**6. mAP50 高，为什么仍有漏检？**

mAP 综合多个置信度工作点，不能直接等同于某一部署阈值的召回率。上线工作点还要看固定阈值下 P/R、类别分布、漏检代价与良品误报。当前阈值目标是验证集微平均 F1，只适合作品集，不代表工厂成本最优。

**7. 为什么重复框不能算两次正确？**

匹配按预测置信度排序，一张真值框最多匹配一次；多余预测计为 FP。代码有明确的重复预测测试，避免评价虚高。

**8. OpenCV 基线怎么做？**

可选 ECC 估计平移；对原图和模板做 Otsu 二值化；通过膨胀容忍小幅边缘错位；分别找新增和缺失区域；闭运算连接小间隙；连通域过滤小噪声并输出带边距的框。配准异常或位移超过限度会明确报错，不返回“合格”。

**9. 如何复现结果？**

查看下载选择 manifest、数据审计、训练参数、模型 SHA256、环境锁定文件、验证阈值扫描和逐图测试结果。固定种子减少随机性，不保证所有平台位级一致。

**10. 怎么证明是能用的工程项目？**

现场启动并切换样例，调整阈值后重新检测，查看误检，保存复核，导出报告，再打开实验页查看真实结果。可以演示错误模板尺寸的明确报错和空检测时仍需复核的提示。

## 写进简历前的四个练习

1. 手算一组 xyxy→YOLO 坐标，并在转换代码中找到对应实现。
2. 用同一张测试图将阈值从 0.1 改为 0.6，解释框数变化；不要用测试结果重新选择最优阈值。
3. 找一张漏检图，区分小目标、类别混淆、定位偏差和阈值过滤，写一段自己的分析。
4. 复制项目跑一次小实验，改变输入尺寸，在固定协议下记录精度与耗时；将真正做过的改动作为个人职责说明。
